About Color Sort Puzzle

Color Sort Puzzle is a free online sorting game that runs in the browser with no download or account. Move colored balls between tubes so every tube ends up holding a single color. Every board is generated backwards from a solved state, so it is always solvable, and unlimited undo lets you step back out of any dead end. The difficulty ramps from 3 colors up to 5, making it a calm but brain-teasing color sort puzzle for short breaks.

How to Play

Quick steps to start Color Sort Puzzle on Prism Arcade.

  • 1. Tap a tube to pick up the top balls from it.
  • 2. Tap another tube to pour them in.
  • 3. You can only pour onto an empty tube or a tube whose top color matches.
  • 4. Sort every color into its own tube, using Undo if you get stuck.

How do I play Color Sort Puzzle?

Tap a tube to pick up its top balls, then tap another tube to pour them. You can only pour onto an empty tube or one whose top color matches, and a tube holds four balls.

Is every Color Sort board solvable?

Yes. Each board is generated from a solved arrangement, so a winning sequence always exists, and you can use unlimited undo if you get stuck.
